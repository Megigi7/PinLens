# Política de privacidad de PinLens

**Última actualización:** 19 de agosto de 2026

## 1. Sobre PinLens

PinLens es una aplicación personal y experimental destinada a explorar, organizar y filtrar contenido de Pinterest mediante funcionalidades que no están disponibles en la interfaz estándar de Pinterest.

La aplicación utiliza la API oficial de Pinterest para acceder a datos de Pinterest cuando una cuenta autoriza expresamente dicho acceso mediante el sistema de autenticación OAuth proporcionado por Pinterest.

## 2. Datos a los que puede acceder PinLens

Dependiendo de los permisos concedidos mediante OAuth y de las capacidades disponibles en la API de Pinterest, PinLens puede acceder a información relacionada con:

* Cuentas de Pinterest que hayan autorizado la aplicación.
* Pines y tableros a los que la aplicación tenga acceso.
* Secciones de los tableros cuando dicho acceso esté permitido.
* Metadatos asociados a los Pines, como identificadores, títulos, descripciones, enlaces, colores dominantes y otra información proporcionada por Pinterest.
* Imágenes o URLs de imágenes asociadas a los Pines cuando sean necesarias para las funcionalidades de análisis visual y el acceso esté permitido.

PinLens no solicita ni almacena las contraseñas de las cuentas de Pinterest. La autenticación se realiza mediante OAuth y los permisos concedidos por Pinterest.

## 3. Finalidad del acceso

Los datos obtenidos mediante la API de Pinterest se utilizan exclusivamente para desarrollar, probar y proporcionar funcionalidades de búsqueda, filtrado y análisis de contenido.

Entre las funcionalidades previstas se incluyen:

* Filtrado de Pines por color.
* Análisis de propiedades visuales de las imágenes.
* Búsqueda de Pines y tableros.
* Experimentación con métodos de búsqueda que no están disponibles en la interfaz estándar de Pinterest.

Una finalidad específica de la fase experimental de PinLens es investigar si una cuenta de Pinterest que ha autorizado la aplicación puede acceder, mediante las capacidades permitidas por la API y los permisos concedidos, a Pines y tableros pertenecientes a otra cuenta de Pinterest que sean accesibles públicamente.

PinLens no pretende eludir los mecanismos de autorización, privacidad o control de acceso de Pinterest.

## 4. Uso compartido de los datos

PinLens no vende, alquila ni comparte con terceros los datos obtenidos mediante la API de Pinterest.

Los datos se utilizan únicamente para las funcionalidades de PinLens y para el desarrollo y las pruebas de la aplicación por parte de su desarrolladora.

PinLens no utiliza los datos obtenidos de Pinterest para publicidad ni para crear perfiles comerciales de los usuarios.

## 5. Almacenamiento de los datos

PinLens está diseñado inicialmente como una aplicación local de uso personal.

Los datos obtenidos de Pinterest pueden mantenerse temporalmente en memoria durante la ejecución de la aplicación.

En futuras versiones, la aplicación podría almacenar determinados datos localmente, por ejemplo resultados derivados del análisis de imágenes, con el objetivo de evitar repetir operaciones costosas.

Los datos almacenados localmente permanecerán en el entorno controlado por la propietaria de la aplicación y no serán enviados a terceros salvo que se indique expresamente en una futura versión.

## 6. Servicios de terceros

PinLens utiliza la API oficial de Pinterest para acceder a contenido de Pinterest.

El uso de Pinterest y el tratamiento de datos realizado por Pinterest están sujetos a las políticas de privacidad, términos de servicio y demás condiciones aplicables de Pinterest.

## 7. Seguridad

PinLens utiliza el sistema de autorización OAuth proporcionado por Pinterest.

La aplicación no solicita ni almacena las contraseñas de los usuarios de Pinterest.

Las credenciales de aplicación, secretos y tokens de acceso deben mantenerse privados y no deben publicarse en repositorios públicos.

## 8. Conservación y eliminación

PinLens está diseñado para conservar la menor cantidad de datos posible.

Los datos mantenidos localmente pueden eliminarse directamente del entorno donde se ejecuta la aplicación.

PinLens no intentará acceder a recursos de Pinterest cuando no disponga de una autorización válida para hacerlo.

La revocación de la autorización de PinLens por parte de una cuenta impide que la aplicación continúe accediendo a los recursos protegidos mediante dicha autorización.

## 9. Cambios en esta política

Esta política puede actualizarse cuando cambien las funcionalidades de PinLens, sus prácticas de tratamiento de datos o los requisitos y capacidades de la API de Pinterest.

La versión más reciente de esta política estará disponible en la misma dirección en la que se publique este documento.
